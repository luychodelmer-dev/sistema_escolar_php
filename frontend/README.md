# Frontend

Las pantallas públicas del sistema están en `../public/`, que es la carpeta que debe exponerse al navegador.

- `public/login.php`: inicio de sesión.
- `public/asistente/`: pantallas de operación diaria.
- `public/director/`: pantallas de administración.
- `public/assets/`: imágenes y recursos visibles.

Se mantiene el nombre `public` porque es el punto de entrada configurado actualmente por el servidor web.
